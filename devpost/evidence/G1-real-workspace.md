## What is real, and how it got there
- Source: `bridge/project-discovery.mjs` scanned the two **approved** git roots in `bridge/approved-roots.json`
  (`D:\earthproof\lens\EarthProof`, `C:\Users\lalwa\mnemosyne`; consent record `grantedBy: user request 2026-11-08`). Both repos are public on GitHub.
- The scan was fetched from the running bridge (`GET http://127.0.0.1:8787/workspace`) and **bundled into the Lens as a snapshot**:
  `Assets/Scripts/BuildAliveWorkspaceSnapshot.ts`, generated by `devpost/tools/gen-workspace-snapshot.mjs` (scannedAt 2026-11-09T00:14Z,
  EarthProof@02a5921 247 files, mnemosyne@7ff2a04 113 files).
- **It is a snapshot, not a live feed.** The Lens cannot open `ws://127.0.0.1` in Preview unless Lens Studio Experimental APIs is enabled
  (see `devpost/test-results.md` section 6), so the scan is bundled and the banner says so: `REAL REPO SCAN (snapshot 2026-11-09) | <repo> | no live agent event`.
- The same validator (`validateWorkspaceWorlds`) the live WebSocket path would use checks the snapshot; the live path (`bindWorkspace` with "LIVE BRIDGE SCAN") is unchanged.
