# Threat Model & Security Boundaries — BUILD ALIVE (2026-11-08)

## 1. Assets & Trust Boundaries
1. **Developer Host Workspace & Source Code (`D:\earthproof\lens\EarthProof` & user repos):** High-value asset. Must never leak secrets (`.env`, API keys, bearer tokens, `.mcp.json`, SSH keys, private file paths) into Lens telemetry, Git commits, or video captures.
2. **Coding Agent Stream (Claude Code Hooks / Codex Event Stream):** Untrusted input boundary. Agent outputs or repository files may contain prompt injections, malformed JSON, huge payloads, or accidental credentials.
3. **Local Capture, Redaction & Normalizer Service (`bridge/redactor.mjs` & `Assets/Scripts/BuildAliveCore.ts`):** Security enforcement point that scrubs, aliases, validates, and bounds every event before storage or WebSocket broadcast.
4. **SPECS Lens Client (`Assets/Scripts/BuildAlive*`):** Untrusted UI surface for host mutation. A pinch gesture in AR must **never** execute arbitrary shell commands or auto-approve unverified agent tool requests.
5. **Allowlisted Host Action Bridge (`bridge/action-gate.mjs`):** Fail-closed execution gate. Only executes pre-registered, zero-argument allowlisted action IDs after explicit human approval and receipt signing.

## 2. Threat Matrix & Implemented Mitigations (Verified by Automated Negative Tests)

| Threat ID | Threat Description | Attack / Failure Vector | Implemented Mitigation | Verification Test |
|---|---|---|---|---|
| **T01** | **Secret & Credential Leakage** | Agent hook or test output includes `sk-...`, `ghp_...`, `gho_...`, `Bearer ...`, `AIza...`, AWS keys, or `.env` assignments. | `scrubSecrets()` (`BuildAliveCore.ts` & `bridge/redactor.mjs`) strips all known token patterns, `.env` key-values, Authorization headers, and high-entropy secret assignments, replacing them with `[REDACTED_SECRET]`. Restricted filenames (`.env*`, `.mcp.json`, `*secret*`, `*key*.pem`) are blocked from `fileAliases`. | `build-alive.sweep.mjs` (`T01_secret_redaction_suite` — 120 negative payloads) |
| **T02** | **Path Traversal & Host Path Disclosure** | Event `fileAliases` contains `../../Windows/System32`, `C:\Users\lalwa\...`, `/etc/passwd`, or UNC paths `\\server\share`. | `sanitizeFileAlias()` rejects any path with `..`, drive prefixes (`[A-Za-z]:`), leading `/` or `\`, null bytes, or non-printable chars; maps absolute repo paths strictly to allowlisted relative module aliases. | `build-alive.sweep.mjs` (`T02_path_traversal_suite` — 100 negative payloads) |
| **T03** | **Arbitrary Command Execution from AR Pinch** | Malicious or compromised WS message requests shell execution (`rm -rf`, `curl`, `powershell -enc ...`) via Approval Dock. | `PermissionGate` (`BuildAliveCore.ts`) and `bridge/action-gate.mjs` enforce a hardcoded frozen allowlist of 3 read/test action IDs (`run_known_test`, `open_read_only_diff`, `request_explanation`) with **zero shell interpolation** (`execFile` on fixed script only). Any unknown action ID or shell metacharacter (`;`, `|`, `&`, `$`, `` ` ``) is rejected (`status: "denied"`). | `build-alive.sweep.mjs` (`T03_command_allowlist_suite` — 90 negative payloads) |
| **T04** | **Unapproved / Auto-Triggered Host Mutation** | Agent emits `approval_requested` and attempts to execute before human confirmation, or replays an old approval token. | Two-step state gate (`requestApproval` → `APPROVAL_PENDING` → explicit user `approveAction(requestId, actorConfirmation)` with matching nonce + scope check) producing an immutable SHA-256-like deterministic audit receipt (`receiptId`). Duplicate or expired approvals are rejected. | `build-alive.sweep.mjs` (`T04_approval_nonce_replay_suite`) & LEAF `L17` |
| **T05** | **Prompt Injection / Control-Character Spoofing in Evidence Cards** | Repository diff or test output contains ANSI escape codes (`\x1b[...`), zero-width characters, or fake `[PASS]` status prefixes designed to spoof the AR HUD. | `sanitizeDisplayText()` strips all ASCII control characters (`0x00–0x1F`, `0x7F`), ANSI CSI sequences, and bidirectional override characters, and truncates strings to `<= 120` chars before rendering. | `build-alive.sweep.mjs` (`T05_ansi_and_spoof_sanitization`) |
| **T06** | **Event Flood / Out-of-Order / Memory Exhaustion** | Rapid hook loop emits 10,000 events or out-of-order/duplicate `seq` numbers to stall the Lens frame rate. | `ReplayStore` enforces monotonic `seq` ordering, idempotent `eventId` deduplication, payload size cap (`<= 4096` bytes), and a bounded ring buffer (`MAX_EVENTS = 128`). Scene objects are pooled (`<= 18` meshes). | `build-alive.sweep.mjs` (`T06_flood_and_ordering_suite` — 500-event burst test) |
| **T07** | **WebSocket Origin & Session Spoofing** | Local webpage in browser attempts cross-origin WebSocket connection to `ws://127.0.0.1:8787/build-alive`. | `bridge/ws-server.mjs` binds strictly to `127.0.0.1`, rejects browser `Origin` headers not on the local allowlist, and requires a per-session handshake token for any action receipt. | `build-alive.sweep.mjs` (`T07_ws_origin_and_auth_check`) |
| **T08** | **Misleading Provenance (Fake Live Demo)** | Disconnected preview or mocked LLM response masquerades as a live verified agent connection. | Every state snapshot and UI header carries an explicit `ProvenanceMode` enum (`LIVE_VERIFIED`, `LOCAL_RECORDED_REPLAY`, `PREVIEW_SIMULATION`, `NOT_CONNECTED`). Disconnection immediately transitions to `LOCAL_RECORDED_REPLAY` / `OFFLINE` and disables host execution (`fail closed`). | LEAF `L19` & `build-alive.sweep.mjs` (`T08_provenance_integrity`) |

## 3. Pre-Commit & Pre-Publish Secret Scan Protocol
Before any git commit or push:
1. Verify `.gitignore` excludes `.mcp.json`, `spk_debug_key.pem`, `.env*`, `leaf_plugin_settings.json`, `Cache/`, `Support/`, `Workspaces/`.
2. Run `git grep -E "(Bearer |ghp_|gho_|sk-[A-Za-z0-9]{20}|AIza[0-9A-Za-z-_]{35}|PRIVATE KEY)"` across all tracked files and verify zero matches.
